# Jeffrey Support

Need help? Choose the option that works best for you.

1. **GitHub Issues** — Report bugs or request features at https://github.com/charlesacquah-davis/Jeffrey/issues.
2. **GitHub Discussions** — Ask questions and share tips with other Jeffrey users at https://github.com/charlesacquah-davis/Jeffrey/discussions.
3. **Status Updates** — Follow release notes and maintenance notices in the repository README.

We aim to respond to new issues within two business days.
